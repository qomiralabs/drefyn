# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
[open a private report](https://github.com/qomiralabs/drefyn/security/advisories/new).

Do not open a public issue, pull request or discussion for a security problem.

We will confirm we received your report, keep you updated while we work on a fix, and
credit you in the advisory if you want to be credited.

## Supported versions

Drefyn is in early development and has no releases yet. Fixes land on the latest code.
